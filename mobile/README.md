# Ourpot Flutter clients

This Android/iOS client scaffold uses `/api/v1`, integer minor-unit values, session cookies, password/MFA repository states, and an offline mutation queue with explicit `pending`, `conflict`, and `sent` states.

Flutter is not installed in this repository environment. On a Flutter-enabled machine run `flutter pub get`, `flutter analyze`, and `flutter test`. Passkey integration, secure device storage, and the production UI remain follow-up mobile work.
